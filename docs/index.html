Monorepo Package Architecture

Modular TypeScript packages providing end-to-end design system orchestration.

@terrazzo/cli

CLI Build Executable

High-performance command-line compiler with watch mode, configuration loading, and build pipeline runners.

@terrazzo/parser

DTCG AST Engine

Strict specification parser validating DTCG schemas, alias references, and token dependencies.

@terrazzo/plugin-css

CSS Custom Properties

Transforms tokens into clean, scoped CSS variable manifests with fallback handling.

@terrazzo/plugin-sass

Sass Variable Generator

Generates structured Sass maps and individual variables for legacy SCSS codebases.

@terrazzo/plugin-js

Typed TS/JS Exports

Outputs immutable, strongly typed JavaScript & TypeScript design token constants.

@terrazzo/plugin-swift

Swift Native Tokens

Outputs native Swift structs for iOS, iPadOS, and macOS application design systems.
